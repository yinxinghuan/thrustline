# THRUSTLINE 正式版视觉与界面合同

## 1. Thesis

正式 v1 保留用户认可的工业诊断仪表方向：玩家必须一眼看见飞行器、山脊、两个平台、推力状态、速度和预测落点。正式化只增加身份与排行榜壳层，不重做手感或堆叠特效。

## 2. Composition / Camera

固定竖屏正交视图，`360×640` 逻辑场地填充可用空间。HUD 占顶部 `70px`，玩法仍可穿过其下方；山脊位于下部，两个平台同时可见。平台内构图不为外部访客栏让位。

## 3. Color

- 背景 `#f4f2ec`
- 权威山脊/飞行器 `#171717`
- 辅助网格/历史轨迹 `#a9a79f`
- 点火、危险和预测碰撞 `#d4572a`
- 所有状态同时使用文字或形状，不只依赖颜色。

## 4. Typography

系统无衬线，数值等宽；标题 `16px/700`，关键数值 `18–24px/700`，说明文字最小 `14px`。中英仅保留短词，不使用装饰字体。

## 5. Shape / Material / Light

全部为单色线框和实心几何；不模拟材质、灯光、深度、玻璃或金属。飞行器用三角机身和两条腿，点火用单一实心推力楔形。

## 6. Assets

游戏内无外部美术、字体、音频或第三方游戏代码；地形与 UI 由 Canvas/DOM 原生绘制。`alteru-default-avatar.jpg` 只用于缺失头像降级，`poster.png` 只用于平台列表封面，不参与玩法画面。

## 7. UI / Icons

不使用功能 Emoji。HUD 用直接文字；重开按钮使用“立即重开 / RETRY”。唯一玩法控件是整个 Canvas。顶部 `RANK` 与结算页“排行榜 / RANK”打开同一模态层；榜单行使用统一的圆形头像/首字母、名字、名次和分数。

## 8. Motion / VFX

只绘制真实位置、自动摆角、推力楔形、历史轨迹和预测线。无粒子、屏震、辉光、拖影滤镜或装饰动画。`prefers-reduced-motion` 不改变物理，只关闭首屏提示脉冲。

## 9. Translated References

保留 Lunar Lander 的重力、燃料、速度阈值和平台风险；将旋转控制转译为自动摆角，让移动端只需按住/松开，同时保留点火时机决策。

## 10. Anti-patterns

- 不用视觉主题掩盖无趣的物理。
- 不显示键盘或虚拟方向键。
- 不把预测线做成虚假装饰。
- 不隐藏速度阈值或失败原因。
- 不用随机噪声制造不可复验的地形。
- 不让排行榜、身份或访客栏改变 Canvas 相机、场地尺寸和飞行判定。
- 不在平台外伪造实时榜单；明确说明排行榜只在 AlterU 内显示。

## 11. Vertical-slice Acceptance

- ready、playing-thrust、playing-coast、SAFE/HARD/CRASH 结果均可读。
- 两个平台与气流区在 `390×844`、`320×568` 同时可见。
- 首触同帧显示 THRUST，松开后同帧显示 COAST。
- 预测落点与权威碰撞使用同一地形函数，截点误差不超过 `2px`。
- 没有粒子和主题素材时，玩家仍能做燃料、速度和平台选择。
- 平台内榜单能显示自己和其他玩家；其他玩家头像+名字可点击打开资料。
- 外部访客栏可见时只做可用性检查，平台主验收构图始终以访客栏不占位为准。
