# THRUSTLINE 正式版需求

## 1. Overview

THRUSTLINE 是一个 30 秒单指 Lunar Lander 游戏：飞行器自动摆动方向，玩家仅用按住点火、松开滑行，在有限燃料、水平/垂直速度、山脊和不同价值着陆区之间做取舍。

- 场景：AlterU/Aigram 竖屏全屏推荐流；无需开始按钮，首个 `pointerdown` 同帧开始并点火。
- 单局：最多 `30s`；安全着陆、硬着陆或坠毁后可立即重开。
- 目标视口：`390×844` 与 `320×568`。
- 正式版永久 UUID 为 `67bc0e3f-ac83-410f-a802-f4a01d177528`；AlterU 内读取当前玩家身份并提交排行榜，平台外诚实降级为本机试玩与 AlterU CTA。
- 重复边界：现有 Skybound Aviator、Tide Signal、Flappy Bird 属于飞行躲避/收集；本作的胜负由有限燃料、自动旋转推力、着陆区与接触速度共同决定，不复用其核心循环。

## 2. Visual Design

- 只使用黑、白、灰和一种警告橙；无粒子、纹理、渐变、辉光、阴影或主题素材。
- 主体是程序化山脊、两个明确着陆区、飞行器、真实历史轨迹、未来 `1.6s` 的无推力预测线。
- 山脊和着陆区来自同一权威几何函数并参与碰撞；预测线由当前速度、重力和气流计算，用于判断落点。
- HUD 只显示剩余时间、燃料、水平/垂直速度和安全阈值；状态不能只靠颜色。
- 首屏显示“按住点火 / 松开滑行”，第一次有效点火后移除。

## 3. Game Mechanics

### 逻辑场地与时间

- 权威场地宽 `360`、高 `640`；固定步长 `1/120s`。
- 开局位置 `(64, 92)`，初速度 `(18, 5)px/s`；不操作会撞上安全区右侧山脊，必须主动刹降。
- 重力 `38px/s²`；飞行器自动以 `0.97rad/s` 在 `-34°` 到 `+34°` 间往返摆动。
- 推力 `78px/s²`，沿飞行器当前方向施加；最大燃料 `100`，点火每秒消耗 `18`，约可持续 `5.55s`。
- 水平边界为实体山壁；接触即坠毁。顶部越界 `20px` 后坠毁。

### 山脊、着陆区与气流

- 山脊由分段线性高度函数生成，不使用随机噪声。
- 安全区 A：`x=68–146`，地面 `y=574`，宽 `78px`，基础 `1000` 分。
- 风险区 B：`x=266–306`，高台 `y=506`，宽 `40px`，基础 `1900` 分。
- `x=162–232, y=145–500` 为横向气流区，施加 `+24px/s²` 向右加速度；场内用箭头和文字标明，进入/离开同帧更新物理。
- 非着陆区山脊接触直接坠毁；平台与山脊共用连续高度函数，不允许穿透。

### 着陆判定

- 飞行器碰撞使用中心、两条腿和机身四角的权威点，不使用轨迹或视觉线条。
- 接触着陆区时：
  - **SAFE**：`|vx|≤18px/s`、`0≤vy≤36px/s`、`|tilt|≤13°`。
  - **HARD**：`|vx|≤30px/s`、`0≤vy≤48px/s`、`|tilt|≤22°`，且不满足 SAFE。
  - 其他情况为 **CRASH**。
- SAFE 奖励平台基础分 + 剩余燃料 `×8` + 剩余秒数 `×20`。
- HARD 奖励平台基础分 `×0.45` + 剩余燃料 `×3`，不计时间奖励。
- 30 秒耗尽仍未接触平台为 TIMEOUT；燃料归零不会立即失败，但只能滑行。

### 轨迹与预测

- 历史轨迹最多保留最近 `120` 个固定步长采样点，仅表达实际路径。
- 预测线从当前状态向前模拟 `1.6s`、每 `0.1s` 一个点，假设松开点火，但包含重力、气流和山脊交点。
- 预测首个接触点标记为 `SAFE / HARD / CRASH`；它不替代实际碰撞，但必须由同一地形和阈值函数计算。

## 4. Controls

- 唯一玩法输入：主画布 `pointerdown` 点火；`pointerup / pointercancel / lostpointercapture` 松开滑行。
- 第一次 `pointerdown` 从 ready 进入 playing，并在同一逻辑帧启用推力。
- 仅接受一个主指针；第二触点忽略。
- 页面隐藏或窗口失焦时立即取消点火并暂停；恢复后不补算隐藏时间，需再次按住才点火。
- 不实现键盘、虚拟摇杆、方向按钮、倾斜传感器、双指或滑动操作。
- 结果层“立即重开”使用 `click`，触控目标至少 `48×48px`；重开返回 ready，不自动耗油。
- 顶部与结算页的排行榜按钮使用 `click`，不会截获 Canvas 的持续 Pointer 输入。

## 5. Win / Lose Conditions

- SAFE：安全着陆，显示接触时 `vx / vy / tilt`、剩余燃料、平台和得分。
- HARD：硬着陆但飞行器存活，显示超出 SAFE 的具体指标和“若少 X 即安全”的后悔点。
- CRASH：撞山、撞墙、冲出顶部或超出 HARD 阈值，显示首个失败指标。
- TIMEOUT：30 秒未着陆。
- 结果出现后 `120ms` 内重开按钮可用；重开后全部物理、燃料、轨迹和计时重置。
- 得分大于 0 时在 AlterU 内异步提交；网络、身份或排行榜失败不能阻塞结算与立即重开。
- 排行榜显示前 50 名；其他玩家显示头像与名字并可打开其 Aigram 资料，自己显示“你 / YOU”。
- 后续研究目标：10 人真机测试中至少 7 人无需二次解释完成首次大平台、至少 7 人失败后能指出一个可改变的点火决策并主动重开。

## 6. Sound Effects

- 正式 v1 默认静音，不创建 AudioContext，不使用声音掩盖反馈。
- 后续若加入声音，为点火、低燃料、接触、SAFE/HARD/CRASH 建立独立反馈；音频加载失败不得改变物理。
